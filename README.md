# Çayın Ruh Hâli Analizörü

## Ulusal Çay Psikolojisi Enstitüsü — Resmî Yazılım Paketi v0.0.1-beta-ama-ciddi

Bu yazılım, bir fincan çayın iç dünyasını **laboratuvar ortamında** (yani terminalde) tahlil eder.  
Sonuçlar bilimsel görünür, bilimsel değildir. Bu bir özelliktir.

### Ne yapar?
- Demleme süresi, şeker adedi ve limon durumuna bakarak çaya teşhis koyar.
- Teşhisler aşırı resmi, biraz teatral, tamamen gereksizdir.
- Hiçbir çay zarar görmez. (Bardak hariç, o sizin sorumluluğunuz.)

### Kuruluş
```bash
python3 cay_analiz.py
```

Python 3 yeter. Ek paket yok. Çünkü çay sade sever.

### Kullanım örneği
Program sorar:
1. Çay kaç dakika demlendi?
2. Kaç küp şeker?
3. Limon var mı? (e/h)

Sonra size bir **Ruh Hâli Raporu** basar.  
Raporu çerçeveletmeniz önerilir. Notere tasdik ettirmeniz önerilmez.

### Yasal uyarı
Bu yazılım tıbbi tavsiye değildir.  
Psikiyatrik tavsiye de değildir.  
Çay tavsiyesi bile değildir.  
Sadece bir terminal şakasıdır ve bunu böyle kabul etmeniz gerekir.
